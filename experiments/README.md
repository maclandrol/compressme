# Research record

This directory preserves derivations, bounded prototypes and their positive or
negative results. It is separate from the supported library in `src/compressme`
and the fresh-checkout tutorials in `examples/reproduce`.

Some historical scripts refer to the original research machine or downloaded
assets. They are retained to explain the measurements, not presented as portable
entry points. Use the [reproduction tutorials](../docs/tutorials/moljepa.md) for
new model runs and the [optimisation record](../docs/optimization-record.md) for
the accepted and rejected hypotheses.

Generated tensors, extracted checkpoint storage, molecular pickle assets and
temporary runs are excluded from Git. Source and compact text evidence remain
versioned so a negative experiment is not lost when the package is cleaned up.
