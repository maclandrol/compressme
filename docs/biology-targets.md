# Additional target audit, 7 September 2026

This is a compatibility inventory, not a ranking of biological prediction quality. A Hugging Face repository identifies files; it does not establish the input/output contract needed to rewrite a Python model safely. Mol-JEPA, the selected State ST checkpoint, both State SE representations and Boltz-2 have run through pretrained numerical verification in this work.

Current scope: focus on Boltz-2, retain the existing Mol-JEPA/State work and only
the tested NovoMolGen 32M SMILES AtomWise checkpoint. X-Cell and OmniCell have been
removed from the plan; stFormer is set aside because of the archive and backend
work required. Bioptimus H-optimus-0 and H-optimus-1 both returned HTTP 403
`GatedRepo` in the supplied-token weight check, so they are deferred. The check
saved no credential. The historical rows below remain evidence, not active tasks.
`list_targets()` omits these inactive models; `include_inactive=True` retrieves
the older survey explicitly.

The State ST result deduplicates stored state that does not participate in its usual `inputs_embeds` forward pass. It reduces resident and raw tensor storage by 41,982,688 bytes, but removes no active matrix multiplications and should not be advertised as a speedup. The original 471.7MB training checkpoint also contains optimizer state: compare compressed inference weights with original inference weights when reporting model compression. Zero tables already compress well in a lossless packed file, so the 21.25% reduction in stored parameters is chiefly a resident-memory saving, not a 21.25% improvement over an already packed checkpoint.

For the CPU State SE finite-domain artifact, compilation means evaluating `encoder(normalize(protein_embedding[gene]))` once for each allowed gene and storing those results. The unnormalized `gene_embedding_layer` path needs a separate table, and CLS/dataset tokens need their own compiled constants. Counts are added after this encoder, so continuous count inputs remain variable. The AnnData adapter reuses the original dataset and collator with ordered gene names only; it needs no raw protein dictionary. The validated hybrid avoids repeated wide input projections for known gene IDs while retaining the original encoder for arbitrary raw vectors. The original model gene-name helper still requires its external raw protein dictionary; direct access to the removed raw table is outside the adapter. The smaller shared projection-plus-norm proposal failed complete-output checks and remains rejected. See [State usage](state.md) and [finite-domain compilation](finite-domains.md).

The unmodified published SE `FlashTransformerEncoderLayer` was also instantiated with small random weights and passed through the general affine compiler on CPU. Its 8,544 parameters remained unchanged and its output was bitwise identical. The compiler correctly retained nonlinear and residual barriers. The class calls PyTorch SDPA despite its name; enabling the CUDA backend flag does not by itself prove a CUDA dependency. Its SDPA dropout argument remains nonzero in eval unless construction overrides it; the upstream inference loader requests dropout zero.

The selected State ST release needs Transformers 4.52.3: current Transformers 5 rejects hidden width 328 with 12 attention heads even though the checkpoint supplies head dimension 64. A separate `.venv-state` environment avoids changing Mol-JEPA's environment. A second source issue is an eager import of a disabled legacy VCI decoder through an obsolete package name. The local loader defers only that unavailable branch and executes the original ST/base/utility source unchanged. Source hashes, JSON hyperparameters and attribution are included in the portable architecture directory.

The package registry is `compressme.targets`. Detailed reachable-path corrections and the actual OmniCell counterexample are in [the OmniCell/stFormer audit](omnicell-stformer-audit.md). Raw source inventory is in
`benchmarks/cell_model_source_audit.json`; the portable State artifact contains
its source/config hashes and original licenses.
